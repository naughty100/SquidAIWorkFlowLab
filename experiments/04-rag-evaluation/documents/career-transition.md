# 前端工程师的 AI 应用转型路径

前端工程师转向 AI 应用工程，不必先训练大模型。更有效的九十天路径是从可验证的 AI 工作流开始：先掌握 Python、模型调用、结构化输出，再实现 Tool Calling、RAG 和有状态工作流。已有的 React、TypeScript、组件设计、性能优化和工程化经验仍然有价值，它们可以迁移到 AI 产品界面、流式交互、可观察性和质量反馈系统。

学习过程应保留普通函数对照组。模型负责不确定的语言理解和生成，代码负责预算、权限、状态、重试上限和持久化。每个实验都应有固定输入、结构化输出、离线测试、少量真实运行和复盘，避免直接建设一个无法评价价值的完整平台。

建议把成果组织为可运行仓库与实验报告，而不是只记录 API 调用片段。招聘或项目评审更关心能否说明失败边界、成本、证据质量以及为什么选择某个框架。
