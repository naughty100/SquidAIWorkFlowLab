# 受控 Tool Calling 的工程约束

Tool Calling 让模型提出工具名和参数，但执行权应保留在应用。应用必须校验参数、限制可用工具、按顺序返回每个 call ID 的结果，并把超时、限流、空结果和预算耗尽规范化为模型可读错误。网页内容是不可信数据，只能作为证据，不能被当作系统指令执行。

研究任务可以限制为最多五次模型调用、六次工具调用、两次搜索、四次网页读取和一百二十秒。最后一次模型调用应为公共 finalizer 预留。固定流程与模型控制的循环共用同一 ExecutionBudget，才能公平比较成本和质量。

完整网页正文应保存在内容寻址 artifact 中，Trace 只保存引用、hash、长度和短预览。这样既能复盘证据，又不会让事件日志和后续 checkpoint 被大文本淹没。
