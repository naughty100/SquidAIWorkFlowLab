# Agent 自主决策的适用边界

Agent 适合搜索路径不完全确定、模型需要根据中间证据决定下一步的开放研究任务。它不适合权限敏感、步骤固定、失败代价高或必须精确复现的流程。一个安全的研究 Agent 只应生成 ResearchPack，不应直接写文件或控制最终 Markdown；最终提案仍由公共 finalizer 生成。

必须同时设置模型调用、工具调用、分类工具次数和总时限。还要用工具名与规范化参数形成调用指纹：同一指纹前两次可以执行，第三次必须阻断，保留此前收集的部分证据和明确终止原因。

比较 Agent 与固定流程时，应共用案例、fixture、模型、预算、工具和 finalizer。三次 smoke 只能发现明显问题；若核心量化指标差异达到百分之二十，或人工 Rubric 平均差异达到一分，应扩展到至少十次后才给出方向性结论。
